## 7. HeadyBuddy — The AI Companion

### Vision

HeadyBuddy is not another chatbot. It's a **fractal anchor** — a stabilizing presence that connects your immediate actions to your highest values through calm, structured guidance.

### Core Features

#### 🌅 Morning Calibration
Every day begins with one question:
> *"What is the ONE thing today?"*

The system uses yesterday's reflection + calendar data + task priorities to suggest the single most impactful action.

#### 🧠 Overwhelm Protocol
When triggers are detected ("I have a million things", >20 rapid task additions):
1. **Stop** — Do not list the tasks
2. **Validate** — "I hear the volume. It feels heavy."
3. **Narrow** — "We are doing **one thing**. Which makes the most noise stop?"
4. **Hide** — "I've safely stored the other 99. They're not here."

#### 📊 Monte Carlo Planning
Instead of static deadlines, HeadyBuddy uses probability:
- **Input:** 5 tasks with time ranges (10-30 min each)
- **Simulation:** 1000 probabilistic days
- **Output:** "85% chance you finish these 3 by 5 PM. Task 4 is unlikely."
- **Action:** Auto-bump Task 4 to tomorrow to prevent failure feeling

#### 🌙 Evening Reflection
> *"What went well today? What do we learn?"*

Stores reflections in HeadyMemory for long-term pattern recognition.

### UX Constraints (By Design)
- **No Red Badges** — Never show "99+ Overdue"
- **Collapsed Backlogs** — Everything not "Today" is hidden by default
- **Single-Task Mode** — "Focus" view shows ONLY the current active item
- **Maximum 3-7 items** visible at any time
